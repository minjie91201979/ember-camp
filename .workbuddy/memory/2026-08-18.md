## 新增：天气系统（纯视觉，按区域主题自动）
- 新文件 `src/render/weather.ts`：`WeatherView` 类，相机锚定的 `THREE.Points` 粒子层，canvas 生成贴图（dot/streak/leaf/mist），屏幕边界回绕。
- `GameRenderer` 三处接钩：构造里 `scene.add(weather.group)`；`rebuildZone` 里 `weather.setTheme(sceneTheme.id)`；`render()` 末尾 `weather.update(...)` + 雨暴风 `stormFactor` 加浓雾/压曝光。
- 主题→天气映射：frost=雪、dunes=飞沙、ashland/throne=飘烬、mire/coast/mistnight/abyss/void=浮雾、woodland=落叶、ridge=淡雪、quarry=无。
- 性能：单 Points + 共享贴图，~70–340 粒子，开销极低。构建 `npm run build` 通过（tsc + vite 108 模块）。
