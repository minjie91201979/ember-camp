## 1. 高概念

玩家从边境营地「烬营」出发，在横版区域中清怪、捡装、升级，击败区域 BOSS 后解锁下一块地图，最终通关 60 级终焉王座。

对标体验：横版手感接近《死亡细胞》的左右移动与跳跃战斗；成长与掉落接近暗黑式装备；枢纽营地接近魔兽世界的主城（商人 + 传送）。

一句话：**营地补给 → 进图打怪捡装 → 回营强化 → 打 BOSS 开下一区。**

---

## 2. 核心循环

```
选职业 / 读档
    → 烬营（补给、交易、传送）
        → 世界地图选区域
            → 区域横版关卡（清怪、精英、材料）
                → 区域 BOSS
                    → 掉落结算、解锁传送点
                        → 回营（修理、卖装、买药、强化、加点 / 换专精）
```

单次出击目标：在当前等级段区域刷满经验与装备，或专门打 BOSS 拿关键掉落。死亡惩罚轻：掉耐久、损失部分未拾取掉落，不掉已装备物品与金币。

## 3. 职业

四种职业，创建时锁定，不可转职。成长分三层：**等级自动成长**、**自由属性加点**、**技能点 + 专精**。技能库与加点规则见第 5 章；本节只定职业身份。

### 3.1 属性分两层

**主属性**（可加点，见 5.3）：力量 STR、敏捷 AGI、智力 INT、体质 VIT、精神 SPI。

**派生属性**（由主属性、装备、技能、专精汇总，面板展示）：

| 属性 | 作用 |
| --- | --- |
| 生命 HP | 归零则战败 |
| 职业资源 | 怒气 / 法力 / 集中 / 能量，见各职业 |
| 攻击 ATK | 物理技能与普攻基础伤害 |
| 法术强度 SP | 法术技能基础伤害 |
| 防御 DEF | 减免物理伤害 |
| 魔抗 MR | 减免法术伤害 |
| 暴击率 CRIT | 属性贡献上限 40%，总计上限 60% |
| 暴击伤害 CDMG | 默认 150% |
| 移速 MOVE | 跑动与后撤 |
| 攻速 ASPD | 普攻间隔 |
| 急速 | 缩短技能冷却，软上限 30% |

### 3.2 战士 Warrior

近战持续输出，生存最高。

| 项 | 设定 |
| --- | --- |
| 主属性 | 力量 STR |
| 护甲类型 | 板甲 |
| 资源 | 怒气 Rage，0–100。普攻与受伤积攒，脱战每秒衰减 |
| 武器 | 单手剑 + 盾，或双手斧 / 双手剑 |
| 定位 | 站桩、近身、抗伤 |
| 主属性加点 | 力量；生存点体质 |
| 1 级被动 | 持盾时可格挡正面伤害 |

核心手感：冲锋进场，旋风清波，斩杀收残血。技能库见 5.4。

### 3.3 法师 Mage

远程法术爆发，生存最低，强依赖蓝水。

| 项 | 设定 |
| --- | --- |
| 主属性 | 智力 INT |
| 护甲类型 | 布甲 |
| 资源 | 法力 MP，脱战自动回复，战斗中回复很慢 |
| 武器 | 法杖 或 魔导书 |
| 定位 | 远程爆发、贴身靠冰环 / 闪现保命 |
| 主属性加点 | 智力；续航点精神，生存点体质 |
| 1 级被动 | 法术暴击返还少量法力 |

核心手感：边走边放火球，冰霜新星防贴脸，闪现躲扫屏。技能库见 5.4。

### 3.4 猎人 Hunter

远程物理，风筝与陷阱。

| 项 | 设定 |
| --- | --- |
| 主属性 | 敏捷 AGI |
| 护甲类型 | 锁甲 |
| 资源 | 集中 Focus，0–100，静止或攻击回复，疾跑消耗 |
| 武器 | 弓 / 弩 |
| 定位 | 保持距离、陷阱控场 |
| 主属性加点 | 敏捷；生存点体质 |
| 1 级被动 | 对 8 米外目标伤害 +8% |

核心手感：后跳拉开，陷阱挡路，瞄准打精英。一期无常驻宠物。技能库见 5.4。

### 3.5 盗贼 Rogue

近战爆发，高机动、低容错。

| 项 | 设定 |
| --- | --- |
| 主属性 | 敏捷 AGI |
| 护甲类型 | 皮甲 |
| 资源 | 能量 Energy，0–100，快速回复；技能叠连击点 0–5 |
| 武器 | 双匕首，或单手剑 + 副手匕首 |
| 定位 | 切入、爆发、脱离 |
| 主属性加点 | 敏捷；爆发可点力量 |
| 1 级被动 | 消失结束或破隐后的第一击暴击率提高 |

核心手感：影袭叠连击点，刺骨打爆发，消失是短脱离而不是潜行玩法。技能库见 5.4。

## 4. 战斗（横板）

### 4.1 空间与镜头

- Three.js 场景：X 为前进轴，Y 为跳跃，Z 为分层景深（前景 / 角色层 / 远景）。
- 摄像机锁定角色，左右跟拍，垂直方向轻微补偿跳跃。
- 关卡为一条可分支的横版路径：主路 + 少量高台 / 密道。
- 碰撞：地面、平台、墙、击退边界。不做完整开放 3D 移动。

### 4.2 操作（键鼠，手柄后期）

| 操作 | 默认 |
| --- | --- |
| 左右移动 | A / D 或 ← → |
| 跳跃 | Space |
| 普攻 | 鼠标左键 |
| 技能 1–4 | Q E R T |
| 药水（红 / 蓝） | 1 / 2 |
| 闪避 / 翻滚 | Left Shift |
| 打开背包 | I |
| 角色（加点） | C |
| 技能与专精 | K |
| 打开地图 | M |
| 与 NPC / 传送交互 | F（靠近时） |
| 暂停 | Esc |

翻滚有短暂无敌帧（约 0.2s）与冷却。

### 4.3 伤害公式（实现用）

```
物理伤害 = max(1, ATK * 技能系数 * 技能等级倍率 * (1 - DEF / (DEF + 200)))
法术伤害 = max(1, SP  * 技能系数 * 技能等级倍率 * (1 - MR  / (MR  + 200)))
若暴击：再乘 CDMG
等级差：目标高出 5 级以上，命中与伤害额外衰减
```

`ATK` / `SP` 由主属性折算 + 装备决定，见 5.3。技能等级倍率见 5.4。怪物对玩家同公式。BOSS 技能可带独立系数。

### 4.4 战斗节奏

- 小怪成波（3–8 只），精英单独或带 2 只小怪。
- 怪物有仇恨距离与脱战距离，不会无限追出区域边界。
- 玩家可随时开地图回营（战斗中需读条，被打断则取消）。
- BOSS 战禁止回营，死亡直接失败并回营。

## 5. 等级、加点与技能（1–60）

升级立刻回满生命与职业资源，并同时获得：

| 获得 | 数量 | 用途 |
| --- | --- | --- |
| 职业自动成长 | 见 5.3 成长表 | 即使乱点也不会完全废号 |
| 属性点 | 4 | 自由分配到五项主属性 |
| 技能点 | 1 | 学习 / 升级主动技能 |
| 专精节点 | 仅 10 / 20 / 30 / 40 / 50 / 60 | 三选一，定玩法路线 |

未分配的属性点、技能点可一直留着，HUD 上「角色 / 技能」按钮显示红点。战斗中不可加点；安全区或暂停菜单可加。

### 5.1 升级来源

- 击杀怪物、精英、BOSS 获得经验。
- 本期不做任务线；首次击败区域 BOSS 额外给一包经验。
- 经验表用 `level-exp.json` 配置。约束：60 级可达到，前 10 级要快。

| 等级段 | 建议时长 | 成长重点 |
| --- | --- | --- |
| 1–10 | 短 | 学会加点、装上 4 个技能、10 级选专精 |
| 11–30 | 中 | 技能升到 3 级，换装成型 |
| 31–50 | 中长 | 专精定型，强化装备 |
| 51–60 | 长 | 刷 BOSS 橙装，技能 4–5 级 |

### 5.2 战力构成（优先级）

1. 装备品质与 ilvl  
2. 技能等级 + 专精  
3. 属性加点  
4. 装备强化  
5. 角色等级自带成长  

约束：低 5 级的稀有装应强于同级白装；把 4 点全砸主属性，也不应超过一件同级蓝装的提升。乱点副属性会变弱，但靠自动成长仍能打过建议等级区。

### 5.3 属性加点

五项主属性，**不锁职业**，任意职业可点任意属性。面板用「主 / 副」标签提示，不强制。

| 主属性 | 主要收益 | 次要收益 |
| --- | --- | --- |
| 力量 STR | 物理 ATK | 少量生命 |
| 敏捷 AGI | 暴击率、攻速、猎人/盗贼物理 ATK | 少量急速 |
| 智力 INT | 法术强度 SP、法力上限 | 少量魔抗 |
| 体质 VIT | 生命、防御 | — |
| 精神 SPI | 资源回复、魔抗 | 法力上限（法师更明显） |

#### 1 级基础值

| 职业 | STR | AGI | INT | VIT | SPI |
| --- | --- | --- | --- | --- | --- |
| 战士 | 12 | 6 | 4 | 10 | 5 |
| 法师 | 4 | 6 | 12 | 6 | 9 |
| 猎人 | 6 | 12 | 5 | 8 | 6 |
| 盗贼 | 8 | 12 | 4 | 7 | 6 |

1 级额外给 4 点属性、1 点技能，可在创建确认前按推荐方案一键分配（仍可手改）。

#### 每级自动成长（不消耗属性点）

| 职业 | STR | AGI | INT | VIT | SPI |
| --- | --- | --- | --- | --- | --- |
| 战士 | 2 | 0 | 0 | 2 | 0 |
| 法师 | 0 | 0 | 2 | 1 | 1 |
| 猎人 | 1 | 2 | 0 | 1 | 0 |
| 盗贼 | 1 | 2 | 0 | 1 | 0 |

#### 折算（实现用，可微调但勿改结构）

```
HP   = 80 + VIT * 12 + STR * 2 + 等级 * 8 + 装备
ATK  = 武器攻击
     + STR * (战士 1.2 / 盗贼 0.4 / 猎人 0.3 / 法师 0.1)
     + AGI * (猎人 1.1 / 盗贼 1.0 / 战士 0.2 / 法师 0.1)
SP   = 武器法强 + INT * (法师 1.4 / 其他 0.2)
DEF  = 护甲 + VIT * 0.6
MR   = 装备 + SPI * 0.5 + INT * 0.2
CRIT = min(40%, AGI * 0.15%) + 装备     // 再与总计 60% 封顶
ASPD = 武器间隔 * (1 - min(30%, AGI * 0.08% + 装备))
资源回复 = 职业底值 + SPI * 系数
```

副属性不是废物（体质永远加血），但 **输出主要吃本职业那一行系数**。法师堆力量几乎不加火球伤害。

#### 重置

营地 **训练师** 可重置：

| 项目 | 规则 |
| --- | --- |
| 属性点 | 退回全部已点属性点（不影响自动成长） |
| 技能点 | 遗忘已学技能，点退回；技能栏清空 |
| 专精 | 取消专精与后续节点，10 级起可重选 |
| 费用 | 每项第一次免费；之后金币 = `20 × 当前等级 × 该项已重置次数` |
| 限制 | 非战斗；BOSS 房内不可 |

属性与技能可分开重置，避免改两个技能却被清掉全部加点。

### 5.4 技能系统

#### 规则

- 每职业 **技能库 8 个主动技能**，**技能栏 4 格**（Q / E / R / T）。
- 普攻、翻滚不是技能，不占栏、不耗技能点。
- **学会**一个技能：满足等级、花 1 点，默认进栏（栏满则只学会、需手动拖到栏上）。
- **升级**：最高 5 级。从 1→5 的技能点消耗为 **1 / 1 / 2 / 2 / 3**（满级共 9 点）。
- 60 级共 60 技能点：满 4 个技能 = 36 点，剩余可把另外几个点到 1–2 级备用，或把核心技点满。**不可能把 8 个技能全部满级**。
- 战斗中可放已装备的技能；换栏、学技能仅在安全区或暂停菜单。
- 技能等级倍率：1 / 1.12 / 1.24 / 1.40 / 1.60 级。3 级与 5 级额外带「效果跃迁」（多一段控制、多一发弹道等），不只有数字。

未学的技能在面板里灰显，写清「需求等级 / 消耗技能点」。

| 刀扇 | 24 | 能量 40 | 身周 AoE，生成 1 点 | 3 级：命中 ≥3 目标时 +1 点 |

消失不做「蹲在原地隐身等背刺」。侧视几乎没有背后，一律按 **短无敌 + 清仇恨 + 破隐加成** 实现。

#### 1 级必学

创建角色时免费学会该职业库中的前两个技能（不耗技能点，视为已学 1 级），并放进 Q / E。1 级仍有 1 点技能，可留给 4 级新技或先把起手技升到 2 级。

### 5.5 专精

10 级必须选一条专精，才能继续获得 20 级起的专精节点。三选一，**同时只能有一条**。专精不耗技能点。

之后在 20 / 30 / 40 / 50 / 60 各从 **当前专精的三个节点里选 1 个**（每档独立三选一，共 5 次）。这样同专精仍有微调，又不必做网状天赋树。

#### 战士

| 专精 | 10 级关键效果 | 适合 |
| --- | --- | --- |
| 防护 | 格挡率提高；盾击冷却缩短；受击积攒更多怒气 | 抗 BOSS 机制 |
| 狂怒 | 怒气获取提高；旋风斩伤害提高；生命越低攻击越高 | 清怪 |
| 武器 | 斩杀伤害提高；暴击伤害提高；冲锋冷却缩短 | 单体 |

后续节点示例（每档三选一，实现用表驱动）：减伤、怒气上限、旋风多一段、斩杀阈值、战吼覆盖普攻、破甲常驻等。数值放 `talents.ts`。

#### 法师

| 专精 | 10 级关键效果 | 适合 |
| --- | --- | --- |
| 火焰 | 火球 / 炎爆暴击提高；暴击附加灼烧 | 爆发 |
| 冰霜 | 新星冻结更久；对冻结目标伤害提高；受击时短暂护盾 | 生存风筝 |
| 奥术 | 飞弹数量 +1；耗蓝技能伤害提高；闪现冷却缩短 | 持续输出 |

#### 猎人

| 专精 | 10 级关键效果 | 适合 |
| --- | --- | --- |
| 射击 | 瞄准射击伤害提高；8 米外加成再提高 | 单体 |
| 生存 | 陷阱冷却缩短；踩陷阱的敌人受伤增加 | 控场 |
| 机动 | 后跳冷却缩短；急速射击期间可移动射击 | 走位 |

#### 盗贼

| 专精 | 10 级关键效果 | 适合 |
| --- | --- | --- |
| 刺杀 | 毒素伤害提高；刺骨对中毒目标额外伤害 | DoT 爆发 |
| 战斗 | 能量回复加快；刀扇 / 攻速提高 | 持续按键 |
| 敏锐 | 消失冷却缩短；破隐第一击伤害提高 | 进场切出 |

60 级时一名角色：自动成长 + 最多 240 自由属性点 + 4 个高技能等级主动技 + 1 条专精 + 5 个专精节点。这是 build 的完整形态。

### 5.6 加点与技能的体验约束

- 升级弹出简短面板：「4 属性点 / 1 技能点」，可稍后。
- 角色页显示每项属性「再点 1 点会加什么」（生命 +12、火球约 +1.4% 等）。
- 技能页可对比栏上技能与库中未装备技能。
- 不提供自动战斗连招；连击点、怒气、蓄力都要玩家按。
- 一期不做第二套技能栏（8 键）。4 键是横板手感上限。

### 6.1 槽位

| 品质 | 颜色 | 词缀数 | 来源倾向 |
| --- | --- | --- | --- |
| 普通 Common | 白 | 0–1 | 小怪、商人 |
| 优秀 Uncommon | 绿 | 1–2 | 小怪、精英 |

### 6.3 词缀池（示例，实现用表驱动）

- 攻击、生命、防御、魔抗

装备有耐久。归零后属性大幅下降，须在营地铁匠处修理（耗金币）。死亡扣耐久，不毁装。

## 7. 掉落、金币与材料

### 7.1 掉落物类型

| 类型 | 用途 |
| --- | --- |
| 装备 | 穿戴或分解 |
| 金币 | 买药、修理、商人、强化 |
| 生命药水 | 战斗中回 HP |
| 法力药水 | 战斗中回 MP / 部分资源（法师刚需；其他职业较少依赖） |
| 材料 | 强化、修理折扣、商人兑换 |

地上掉落为可交互 entiy：走近显示名称，F 拾取。品质用颜色描边。金币自动吸入。

### 7.2 药水分档

| 档位 | 解锁大约等级 | 生命药水 | 法力药水 |
| --- | --- | --- | --- |
| 初级 | 1 | 回 80 HP | 回 50 MP |
| 中级 | 20 | 回 250 HP | 回 150 MP |
| 高级 | 40 | 回 600 HP | 回 350 MP |
| 特级 | 55 | 回 1200 HP | 回 700 MP |

快捷栏各 1 格，堆叠上限 20。战斗内使用有公共冷却约 1.2s。

### 7.3 材料

| 材料 | 来源 | 用途 |
| --- | --- | --- |
| 兽骨 / 皮革 / 布料 | 对应类型小怪 | 分解补充、低级强化 |
| 铁矿 / 秘银 / 瑟银 | 矿区、精英 | 中高强化 |
| BOSS 精华 | 区域 BOSS 必掉 1 | 高级强化、橙装相关 |
| 魔法尘 | 分解蓝装以上 | 鉴定替代：直接用于强化 |

一期不做复杂制造专业。材料主要进铁匠强化：消耗「区域对应材料 + 金币」，成功提高装备强化等级 +1，失败不毁装、只耗材料（成功率随强化等级下降，最高 +8）。

### 7.4 掉落规则

- 小怪：金币 + 低概率白/绿装 + 材料；药水低概率。
- 精英：必金币，较高绿/蓝，材料加倍。
- BOSS：必装备（蓝以上权重），必 BOSS 精华，金币包，药水包。
- 装备掉落按玩家职业权重：60% 本职业可用，40% 随机（可分解）。

## 8. 营地「烬营」

唯一安全枢纽。无战斗、无限修理入口、传送中枢。场景同样用 Three.js 横板空间，但可点选 NPC，不必清怪。

### 8.1 布局（从左到右）

1. 复活点 / 角色出生  
2. 训练师（属性 / 技能 / 专精重置，兼技能书说明）  
3. 铁匠铺  
4. 武器商人  
5. 防具商人  
6. 药水与杂货商人  
7. 材料商人（收购材料、出售基础材料）  
8. 分解台（可与铁匠合并为一个 NPC：铁匠兼分解）  
9. 传送阵（营地最右侧高台）

一期商人类型如下，不另做拍卖行与玩家交易。

### 8.2 NPC 功能

| NPC | 功能 |
| --- | --- |
| 训练师 | 重置属性点、技能点、专精（规则见 5.3）；查看技能说明 |
| 武器商人 | 出售当前等级段白/绿武器；收购玩家武器 |
| 防具商人 | 出售白/绿防具与饰品；收购 |
| 药水商人 | 出售各档红药、蓝药；小堆材料包 |
| 材料商人 | 高价收材料、平价卖基础材料（有限库存刷新） |
| 铁匠 | 修理全部装备；强化；分解装备为材料 |
| 传送阵 | 传送到已解锁区域入口；从区域回营 |

商人库存随玩家等级刷新。收购价约为商店价的 25%–40%。

### 8.3 传送阵规则

- 初始仅「烬营」与「迷雾林地」。
- 首次进入某区域入口，解锁该区域传送点。
- 击败区域 BOSS 后，解锁该区域「BOSS 门前」传送点（方便反复打 BOSS）。
- 世界地图与传送阵共用解锁状态。
- 传送无消耗金币（一期简化）。

## 9. 世界地图与区域地图

### 9.1 世界地图

全屏 UI（React），不是 3D 大世界。节点图：

- 每个区域一个节点，显示名称、建议等级、是否解锁、BOSS 是否击杀。
- 未解锁节点灰显，显示前置条件（通常为「击败上一区域 BOSS」或「达到建议等级」）。
- 烬营固定在地图中心偏左的枢纽节点，放射状连向各区域。
- 可从世界地图直接进入已解锁区域入口，或先回营再走传送阵。

### 9.2 区域地图

进入区域后：

- 小地图：当前横板关卡缩略，显示玩家、已探索路径、精英 / BOSS 图标。
- 区域由 2–4 段横板场景拼接：前哨 → 主野区 → 精英点 → BOSS 门。
- 每段有复活旗帜（安全点），死亡可选择：回最近旗帜（非 BOSS 战）或回营。
- BOSS 房间独立加载，进门后关门。

### 9.3 区域难度

区域有 **建议等级区间**。怪物等级在该区间内随机小幅浮动。越级 5 级以上：命中下降、受伤增加。低 8 级以上：经验大幅衰减，防止无限刷新区。

## 12. 技术架构

### 12.1 栈

- Vite + React 18 + TypeScript
- Three.js（场景、网格、相机、简单光照）
- 状态：游戏模拟与 React 分离  
  - `game/`：纯 TS 模拟（属性、战斗、掉落、存档）  
  - `render/`：Three.js 表现  
  - `ui/`：React HUD

固定时间步（如 1/60s）跑逻辑，渲染插值。避免把战斗写进 React state。

### 12.2 建议目录

```
ember-camp/
  docs/GAME_DESIGN.md
  src/
    app/                 # React 入口、路由式界面状态
    ui/                  # HUD、背包、地图、商店
    game/
      combat/            # 伤害、技能、碰撞粗测
      entities/          # 玩家、怪物、掉落、NPC
      data/              # 职业、技能、专精、区域、掉落表
      systems/           # 升级、加点、背包、经济、存档
    render/              # Three.js 世界、角色、特效
    input/               # 键盘鼠标
```

### 12.3 存档

`localStorage` 一份 JSON：职业、等级、经验、五项主属性（含已分配点）、未用属性点 / 技能点、已学技能与等级、技能栏、专精与节点、背包、已解锁区域、BOSS 击杀、金币、药水、强化。一期单存档槽。

### 12.4 表现范围

灰盒阶段可用几何体占位。成品质感不以灰盒为准，以第 16 章美术标准验收：

- 正交或极浅透视相机，风格化 2.5D，不追求写实。
- 画面靠：轮廓、动画、灯光、雾与后期、特效，而不是面数。
- 不做联网；碰撞自写 AABB / 胶囊。

## 13. 一期范围与非目标

第 13～14 章对应开发流程里的 **Alpha（系统竖切）**，不是 1.0 成品。画面、抛光、耐玩以第 16 章验收。

### 一期要做

- 四职业可选；每职业技能库 8 个（一期可先实装前 4 个，后 4 个数据先写上）
- 自由属性加点 + 技能点升级 + 10 级专精；训练师可重置
- 烬营全部商人 + 铁匠 + 训练师 + 传送阵
- 世界地图 + 12 区域中的 **前 3 区可玩**（1–15 级），其余区域数据先写好、关卡可后续填
- 掉落：装备、金币、红蓝药、材料
- 强化 + 修理 + 分解
- 本地存档

实现顺序建议：先打通「选职业 → 加点/装技能 → 营地 → 进第一区打怪掉落 → 回营买卖 → 打第一个 BOSS → 10 级选专精」。再复制区域管线。

### 明确不做（一期）

- 多人、交易行、公会
- 自由转职
- 网状天赋树、第二套技能栏
- 常驻宠物、坐骑
- 生活职业（采矿需单独小游戏）
- 剧情过场长动画
- 手柄（可后加同一套 input 映射）

## 14. 验收标准（最小可玩）

1. 能创建四种职业之一，看到不同初始武器、资源条，以及 4 点属性 / 1 点技能。  
2. 能自由加点，面板显示「再点 1 点的收益」；能把技能拖到 QERT。  
3. 在迷雾林地内左右移动、跳跃、普攻与技能击杀怪物。  
4. 地上能捡到装备 / 金币 / 药水 / 材料，背包可穿脱。  
5. 回营后能向商人买卖、铁匠修理、训练师重置、传送阵进出第一区。  
6. 10 级能选择专精；击败腐木守卫后世界地图解锁荒石矿坑。  
7. 刷新页面后存档仍在（含加点与技能栏）。

## 16. 开发流程（精良 / 精美 / 耐玩）

目标不是尽快堆出 12 区，而是做出 **手感过关、画面有统一美感、打完一遍还想换 build 再打** 的成品。流程按阶段推进，每阶段有准入和验收；未验收不进入下一阶段扩内容。

假定小团队（1～2 名程序 + 美术可外包或 AI 辅助生产），全长约 **7～10 个月** 到 1.0。人少就拉长，不要跳阶段。

### 16.1 三条品质柱，必须拆进每个阶段

| 柱 | 含义 | 流程里何时锁 |
| --- | --- | --- |
| 精良 | 操作响应、战斗反馈、UI、教程、无脏逻辑、稳定帧率 | 竖切锁定手感；每个系统做完做一次 juice pass |
| 精美 | 统一美术方向、灯光与后期、角色动画、场景氛围、UI 视觉 | 预制作锁风格圣经；竖切锁画面标准；量产只复制该标准 |
| 耐玩 | 职业/专精手感差、掉落追逐、精英词缀、探索秘密、周目与挑战 | 预制作锁支柱；核心系统就要留接口；内容量产后再铺第二周目 |

禁止的顺序：先做完 12 区灰盒 → 最后一周「美化」→ 上线后再想怎么耐玩。那会得到一套能跑的演示，不是成品。

### 16.2 阶段总览

```
0 预制作        锁风格、锁手感目标、锁耐玩支柱、锁工具
1 画面竖切      1 职业 + 营地一角 + 1 段关卡，必须「好看且好听」
2 系统竖切      战斗/背包/加点/技能/掉落/存档 在竖切场景里跑通
3 内容管线      模块化关卡套件、敌人家族、BOSS 框架，能周更一区
4 内容量产      按管线铺区域、BOSS、掉落，同时美术按套件生产
5 耐玩层        词缀精英、秘密、NG+、挑战、build 差异验收
6 整包抛光      全游戏 juice、音画、教学、性能、平衡
7 封版          打磨、回归、发布
```

0～2 串行。3 起美术 / 音频 / 关卡可并行。5 的数据接口必须在 2 就留好。

### 16.3 阶段 0 — 预制作（约 2～3 周）

不写正式关卡。只决定「这游戏长什么样、打起来像什么、凭什么打第二遍」。

**程序**

- 搭 Vite + React 18 + TS + Three.js，固定时间步，逻辑 / 渲染 / UI 分离。
- 角色能在一条灰盒平台上跑、跳、翻滚、攻击，输入延迟可感知地低。
- 正交相机、跟拍、简单碰撞。

**美术（风格圣经，先于量产）**

- 定 **风格化 2.5D**，不走写实。参考方向：轮廓清楚、色板克制、灯光讲故事（类 Hades 的可读性 + Ori 的层次，而不是写实开放世界）。
- 产出：主色板、12 区各一张色稿（可先画 3 区）、角色剪影（四职业一眼可辨）、UI 线框与品质色。
- 定后期：轻微 bloom、色彩分级、雾、环境粒子。过重会糊，过轻会「演示程序」。
- 定资产规则：同一套比例、同一套边缘光、禁止混用风格冲突的素材包。

**设计**

- 锁耐玩三支柱（本项目默认）：**build 差异、掉落追逐、遇敌变化**（精英词缀 + 秘密房间）。
- 写竖切脚本：从主菜单到击杀第一只精英的 3 分钟体验，逐步列出要出现的反馈（命中停顿、伤害数字、掉落光柱、脚步、击中音）。

**本阶段验收**

- 有一份《视觉标准》一页纸（色板、镜头、禁止事项）。
- 灰盒角色移动手感团队认为「能打」——不合格就还在本阶段改，不开始做背包。

### 16.4 阶段 1 — 画面竖切（约 4～6 周）

只做 **迷雾林地前半 + 烬营一角 + 战士**。这一段的画面 = 整款游戏的画面标准。后面 11 区是复制，不是重新发明。

必须包含：

- 分层视差（前景遮挡、角色层、中景、远山/雾）。
- 地面材质连续、平台可读（能站住、能跳上）。
- 战士一套循环动画：闲置、跑、跳、翻滚、普攻、至少 2 个技能、受击、死亡。
- 2～3 种小怪，有受击闪白、死亡解体或倒地。
- 一条完整的灯光：月光/雾林、火把、技能自发光。
- 基础音效：脚步、挥砍、命中、拾取、BGM 一段循环。
- 命中停顿（hit-stop）、轻微屏幕震动、伤害数字、暴击放大。

**本阶段验收（「精美」的门）**

- 录 30 秒无 UI 视频，不看代码也能觉得「这是成品预告片的一截」，而不是几何体演示。
- 60 为目标帧率（中档电脑 / 主流浏览器），掉到 50 以下必须优化后再扩场景。
- 未通过：禁止开始做另外 11 个区域。

### 16.5 阶段 2 — 系统竖切（约 6～8 周）

把第 5～8 章系统做进 **同一段已经好看的关卡**，系统 UI 也必须符合视觉标准，不能突然变成默认浏览器皮肤。

顺序（不要并行堆功能）：

1. 生命 / 资源 / 伤害公式 / 死亡回旗帜  
2. 背包、穿戴、掉落（装备、金币、药水、材料）  
3. 属性加点面板（含「再点 1 点的预览」）  
4. 技能学习、升级、QERT 拖拽  
5. 烬营：铁匠、一个商人、传送阵、训练师重置  
6. 存档读档  
7. 10 级专精选择（可先只做法师或战士一条专精验证）

每做一个系统，当天补：打开/关闭动效、按钮音、错误提示、空态。这是「精良」的来源，不是最后贴的。

**本阶段验收**

- 用战士从建号打到林地 BOSS（可先简化 BOSS），回营卖装加点，刷新浏览器进度还在。
- UI 与世界同一套色板、字体、品质色。

### 16.6 阶段 3 — 内容管线（约 4～6 周）

在扩到 12 区之前，先让「再做一区」变成填表 + 拼模块，而不是重写一关。

必须建成的管线：

| 管线 | 产出 |
| --- | --- |
| 关卡套件 | 地板、斜坡、高台、背景块、可破坏物、秘密墙，按主题换皮 |
| 敌人家族 | 近战、远程、冲锋、自爆/召唤 四种行为模板，换数值与外观即新区 |
| BOSS 框架 | 阶段、读条、可躲红区、召唤、狂暴；新区只填时间轴 |
| 掉落表 | 按区域等级生成 ilvl，配置进 `data/` |
| 场景主题 | 一套灯光 + 雾 + 色级 + 循环 BGM + 环境音 |

用管线 **完整做完 A01 迷雾林地**（含腐木守卫、秘密点、精英），作为样板关。

**本阶段验收**

- 策划改 JSON / TS 数据能换掉落和怪，不改战斗代码。
- 样板关可独立打穿，BOSS 技能可翻滚躲开，不是数值对砸。

### 16.7 阶段 4 — 内容量产（约 8～12 周）

按样板关复制。建议生产顺序：

1. 四职业动画与技能 VFX（战士已有，补法师 / 猎人 / 盗贼）  
2. A02、A03（到 15 级，验证越级与回营循环）  
3. 烬营全 NPC、世界地图  
4. A04–A07  
5. A08–A12 与终焉君王  

每区出货清单（缺一项不算该区完成）：

- 色稿落地（灯光 + 雾 + 地形套件换皮）  
- 3～5 种小怪 + 1 种精英（外观不同、行为来自模板）  
- 1 个 BOSS（可读、可躲、有阶段）  
- 掉落表、材料、药水档  
- 至少 2 个秘密点（隐藏平台、宝箱、捷径）  
- BGM + 环境音 + BOSS 战音乐变化  
- 小地图与传送解锁  

四职业必须在 A03 之前全部可玩；否则后面平衡会返工。

**本阶段验收**

- 四职业都能从 1 打到当前最高区，无断档技能、无缺动画。
- 世界地图 12 节点，未做完的区可以灰显，但已开放区全部达到出货清单。

### 16.8 阶段 5 — 耐玩层（约 4～6 周）

内容铺完只是「能通关」。耐玩在这一阶段做成系统，而不是加更多重复走廊。

必做：

1. **精英词缀**（如加速、冰霜新星、自爆、召唤、吸血），野外随机 1～2 条，掉落更好。  
2. **Build 验收**：12 条专精各打一段同关，手感应可分辨（输出循环、保命手段不同）。过近则改技能/专精，不靠改数值糊弄。  
3. **掉落追逐**：橙装特效真正改技能手感；BOSS 可反复打；图鉴记录已发现橙装。  
4. **探索回报**：秘密房间出独特外观或材料，值得绕路。✅ A01–A12 各 ≥2 秘密；每区独特 `relic-*` 遗物（营地高价出售）；提示与 toast 显示物品名。  
5. **新周目 NG+**：通关终焉君王后开启。怪物等级上浮、词缀更密、掉落 ilvl 封顶上调、外观奖励。不重做 12 张图。  
6. **挑战模式**（可选但建议）：营地开启「词缀地下城」——短横板 + 随机词缀 + 限时，刷强化材料。比再做 12 区更耐玩。

**本阶段验收**

- 通关后仍有明确目标：缺的橙装、NG+、另一职业、挑战层数。
- 同一职业两条专精，录一段清怪，外人能看出循环不同。

### 16.9 阶段 6 — 整包抛光（约 4～6 周）

专门留的阶段，不是「有空再做」。清单按条打勾：

**手感**

- 全技能命中停顿、受击方向、击退、死亡表现统一。✅ hitstop / 击退 / 翻滚无敌  
- 翻滚无敌帧、输入缓冲（落地前 4 帧可跳、攻击可取消进翻滚的规则写死）。✅ 攻击中可取消翻滚  
- 摄像机阻尼、落地尘土、药水使用动作。✅ `R` 喝药 + drink 姿态  

**画面**

- 全区域色级过一遍，避免两区「像换了引擎」。✅ 分区 theme  
- UI 动效、地图揭示、掉落拾取飞向背包。✅ 品质光柱 + 飞向背包（左下 HUD）  
- 过场尽量短：进 BOSS 门关门、击败慢动作，不做长 CG。  

**声音**

- 职业语音可无，但技能、UI、环境、BOSS 必须分层混音。✅ SFX 总线独立；设置可调  
- 音乐：营地安静、野外循环、BOSS 高潮、死亡/升级特效音。✅ BOSS/交战抬紧张度；crit/loot/drink  

**教学与 UX**

- 前 5 分钟无墙：林地里教移动、攻击、翻滚、吃药、拾取。✅ A01 链式教学  
- 加点与技能第一次升级有引导，之后不再打断。✅ toast 一次  
- 所有失败有说明（栏满、蓝不够、未持盾不能盾击）。✅ 背包满 / 怒气不足 / 生命已满  

**技术**

- 性能预算：同屏小怪上限、粒子池、阴影策略。△ 尘土对象池已上  
- 存档兼容、大数字不溢出、平衡表可热改。✅ 换区/BOSS/复活自动存档  

### 16.10 阶段 7 — 封版（约 2～4 周）

- 四职业 1～60 各通一次（可加速调试，但要有一次真人节奏）。  
- BOSS 全打，检查软锁、卡地形、传送错误。  
- 浏览器兼容与分辨率（16:9 优先，超宽左右补黑或延展背景）。  
- 平衡：越级、过级、药剂量、强化曲线。  
- 打磨已知的「别扭」而不是加新系统。

### 16.11 并行分工（阶段 3 起）

| 轨道 | 负责 |
| --- | --- |
| 模拟 | 数值、掉落、AI 模板、存档 |
| 渲染 | 套件、灯光、VFX、动画状态机 |
| UI | 背包、地图、加点、商店、世界地图视觉 |
| 关卡 | 用套件摆关、秘密、BOSS 时间轴 |
| 音频 | 按区出包，不积到最后 |

同一周的目标必须能在竖切标准上运行，不允许「程序先交灰盒区、美术三个月后替换」导致关卡白做。

### 16.12 里程碑（对外可玩版本）

| 版本 | 对应阶段 | 玩家能感到什么 |
| --- | --- | --- |
| Prototype | 0～1 | 30 秒就觉得画面和手感有品位 |
| Alpha | 2～3 | 一个职业能打完样板关并回营养成 |
| Beta | 4 | 四职业、多区、BOSS、世界地图 |
| RC | 5～6 | 通关后还想换专精 / NG+ / 刷橙 |
| 1.0 | 7 | 稳定、好看、教学完整 |

最小可玩（第 14 章）只是 Alpha 门槛，**不是成品定义**。成品以 RC 的耐玩验收 + 竖切的画面标准同时成立为准。

### 16.13 画面与耐玩的硬约束（写进制作）

1. 新技能没有 VFX 和音效，不算完成。  
2. 新区域没有色级、雾、BGM，不算完成。  
3. 新专精若循环与另一条只有数字差，不算完成。  
4. 掉落没有品质色、光柱、拾取音，不算完成。  
5. 帧率不达标时，先减同屏特效，再减画质选项，不默认「能跑就行」。

数据与资源目录预留：`src/game/data/` 配表，`public/assets/` 分 `char/` `zone/` `vfx/` `ui/` `audio/`，从阶段 1 就按此放，避免后期搬家。
