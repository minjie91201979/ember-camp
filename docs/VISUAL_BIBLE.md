# 烬营远征 — 视觉标准

预制作锁定。竖切与量产只复制本页，不另发明风格。写实、赛博、低多边形彩虹风均视为违规。

## 方向

风格化 2.5D 横板。轮廓清楚、色板克制、灯光讲故事。对标可读性接近 Hades，层次接近 Ori，不追求写实皮肤与照片贴图。

镜头：正交（允许极浅透视，禁止自由轨道）。跟拍角色，垂直略补跳跃。背景用雾与视差分层，不用开放 3D 大地图。

## 职业剪影（一眼可辨）

| 职业 | 块面色 | 体型 |
| --- | --- | --- |
| 战士 | 烬橙 `#C45C3E` + 铁灰 | 最宽，可持盾 |
| 法师 | 冷青 `#6E9C9A` + 布袍垂摆 | 最瘦，法杖竖线 |
| 猎人 | 褐 `#8B6A4A` + 弓的弧线 | 中等，披肩 |
| 盗贼 | 暗紫灰 `#5A5360` + 窄肩 | 最矮，双刃短线 |

灰盒阶段用纯色块面代替模型，但必须遵守上表，禁止四职业同色。

## 灯光与后期

- 主光：月光（冷、略侧），辅光：火把 / 技能自发光（暖、局部）。
- 雾近 ~18、远 ~42（世界单位），角色始终从雾中「读得出来」。
- 允许：轻微 bloom（只吃自发光）、ACES 色调映射、很淡的暗角。
- 禁止：强色散、全屏泛光、霓虹描边、每帧晃动的相机。

## 关卡分层（从相机到远）

1. 前景遮挡（树干、岩角，半透明或两侧）  
2. 角色与碰撞层 `z = 0`  
3. 中景（可走平台的视觉延伸）  
4. 远景色块 + 雾  

平台顶面必须比侧面亮一档，玩家要能判断「哪里能站」。

## UI

暗色营地风。面板 `#1A242C`，描边 `#2C3338`，正文月白，标题烬金。不要使用系统默认按钮样式作为终态。HUD 不挡角色中下部。

## 禁止

- 混用风格冲突的素材包（写实皮肤 + 卡通刀光）。
- 无灯光的「白模展厅」。
- 技能没有自发光却靠全屏闪白表示命中。
- 新区域擅自换一套后期（量产只换色级预设，不换引擎感）。

竖切验收：迷雾林地 30 秒无 UI 录像，应能看出本页色板与分层。
