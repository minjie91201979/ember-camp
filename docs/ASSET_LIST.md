# 烬营远征 — 资产清单

依据 `GAME_DESIGN.md`、`VISUAL_BIBLE.md` 与现有效果图整理。当前仓库仍是几何体灰盒，下表均为待生产资产。

未写进本文的资源，默认不做。量产只换主题贴图与色级，不换引擎感。

---

## 0. 约定

| 项 | 规则 |
| --- | --- |
| 根目录 | `public/assets/` |
| 子目录 | `char/` `zone/` `prop/` `vfx/` `ui/` `audio/` |
| 3D | `glTF` / `.glb`，风格化低模，侧视可读，禁止写实皮肤 |
| 2D 贴图 | PNG，sRGB；角色/道具 1024，地砖可平铺 512，UI 图标 256，VFX 条带 256–512 |
| 贴图通道 | 必做 Albedo；金属/自发光件加 Emissive；粗糙度可烘焙进贴图或材质参数。风格化阶段 **不做** 写实法线/照片贴图 |
| 命名 | `kebab-case`，`{域}-{对象}-{变体}`，例如 `char-warrior-albedo.png` |
| 镜头 | 正交 2.5D，角色与碰撞层 `z = 0`，资产按侧视剪影验收 |

### 3D / 2D 分工

| 类型 | 做法 |
| --- | --- |
| 角色、敌人、BOSS、NPC | 3D 网格 + 一套 Albedo（可加 Emissive） |
| 关卡套件、营地建筑、可交互物 | 3D 模块，同模换皮 |
| 远景 / 中景视差 | 2D 竖版或宽幅插画贴在平面上（比全 3D 远山便宜且更像 Ori） |
| 技能、命中、掉落光柱 | 2D 精灵 / 粒子图 + 少量 3D 闪光网格 |
| HUD、背包、地图、图标 | 纯 2D |
| 伤害数字、品质描边 | 2D（字体 + 九宫格框） |
