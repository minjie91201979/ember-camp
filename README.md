## 当前阶段

**阶段 93（已交付）**：法师暴风雪改为魔兽风引导落冰 + 寒冰减速。

需要 Node 18+（本机若用 nvm：`nvm use`，`.nvmrc` 为 20.19.1）：

```bash
nvm use
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。先选职业（或继续存档），再点击画面操作。

| 键 | 动作 |
| --- | --- |
| A / D | 移动 |
| Space / W | 跳跃（点按短跳） |
| Shift | 翻滚 |
| 鼠标左键 / J | 普攻 |
| Q / E / 1 / 2 | 技能栏 1～4（学会后自动进空栏） |
| F | 拾取 / 与营地 NPC 交互 |
| I | 打开 / 关闭背包 |
| L | 橙装图鉴 |
| R | 红药（生命，取最高回复档） |
| T | 蓝药（法力，取最高回复档） |
| Esc | 暂停 / 关闭面板 |
| O | 暂停（同 Esc；含音量） |
| C | 属性加点（可预览） |
| K | 技能学习 / 升级 / 专精 |
| 1 / 2 | 死亡后：回旗帜 / 回营（倒下时优先复活，不放技能） |

### QA 加速（开发 / `?qa=1`）

| 键 | 动作 |
| --- | --- |
| F8 | 开关 QA |
| F1 | 满血满怒 |
| F2 | 升至当前区域等级上限并推荐加点 |
| F3 | 清场（含 BOSS，走正常击杀掉落） |
| F4 | 传送到本区 BOSS 前 |

| F6 | 解锁全部区域 |
| F7 | 补给金币 / 药水 / 材料 |

营地：靠近传送阵 / 训练师（旗旁）/ 铁匠 / 商人后按 `F`。HUD 可存档读档。
